# GenAI exposure scores for ISCO-08 occupations (ILO–NASK Global AI Exposure Index, 2025)

Task-level and occupation-level generative AI (GenAI) exposure scores for the 3,265 tasks of the 427 ISCO-08 four-digit occupations, from the refined global index of ILO Working Paper 140. Scores run from 0 (the task cannot be performed by current GenAI) to 1 (it could be performed entirely by GenAI). Exposure means technical potential. It is not a prediction of job loss.

Interactive explorer: https://pgmyrek.github.io/ai-exposure-explorer/ (a browsable tree view is also in `index.html` in this repository).

## Files

- `Final_Scores_ISCO08_Gmyrek_et_al_2025.xlsx`: scores by task, with the 2023 score, the two model predictions and their justifications, and the final 2025 score
- `4digits_with_tasks.xlsx`, `output_data.json`, `transformation.ipynb`: data and code behind the tree viewer
- `index.html`, `script.js`: the tree viewer
- `Gmyrek et al. 2025, ILO Working Paper 140_web.pdf`: the working paper

Companion data for Poland's national six-digit classification: https://github.com/pgmyrek/POLAND_2025_GenAI_scores_6digit_occupations
